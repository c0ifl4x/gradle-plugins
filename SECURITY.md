# Security policy

## Supported versions

Only the latest major release of each plugin module is actively supported with security updates.

| Version | Supported |
| :--- | :--- |
| `1.x.x` | Yes |
| `< 1.0.0` | No |

## Reporting a vulnerability

If you discover a security vulnerability (such as credential leakage in build logs, command injection in process
wrappers, or unsafe artifact handling), please report it responsibly:

1. **Do not** open a public GitHub issue for security vulnerabilities.
2. Contact the maintainer directly via email or private security advisory on GitHub.
3. Include a clear description of the issue, steps to reproduce, and potential impact.

You can expect an acknowledgment within 48 hours and a fix or mitigation plan as soon as the issue is verified.
